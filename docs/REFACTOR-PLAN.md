## 1. 사용자 결정 (확정)

### 공통
- 게임 사이에 겹치는 기능(채팅, 이모티콘·사진·사운드, 소리 버튼, 나가기, 설정, 게임 시작, 방장, 끊김, 프로필, 창)은 하나로 묶는다. 게임을 언급하지 않은 요청은 모든 게임에 적용한다.
- 예외(규칙상 달라야 하는 것)는 총괄이 판단해 유지한다: 라이어 단계별 채팅 잠금·정체 공개 중 매체 금지, 갱식마인드 정답 판정·정답자끼리 글 가리기·그리는 사람 채팅·이모티콘 금지, 요트 끊긴 차례 기다림. 예외는 NEW-GAME.md 4절 표에 적는다.
- 라이어 폴더를 gamemine 과 같게 유지하는 약속은 **푼다**(gamemine 은 더 이상 쓰지 않는다). 이 저장소가 라이어의 원본이다.
- 모든 무작위(섞기, 뽑기, 라이어 고르기, 순서)는 조작 없는 완전 랜덤. 전수 점검 + 치우침 시험을 넣는다. (포커 섞기는 확인함: 52장, Fisher-Yates, crypto 난수.)
- 기기: 태블릿(iPad Safari)과 컴퓨터 위주. 휴대폰 화면은 신경 쓰지 않는다. 세로로 긴 창을 "가로로 돌려주세요"로 막는 것은 의도다.
- 보안 강화는 필요 없다. 서버가 굴러가는 데 문제없으면 된다. (비밀이 다른 기기로 가는 것은 막는다.)
- 상점은 나중에 사용자가 따로 대폭 고친다. 이번에는 건드리지 않는다. 다만 칭호·이름·프로필 꾸미기·채팅 효과는 공용 프로필·공용 채팅이 그리게 해서 모든 게임에 자동 적용되게 한다.

### 공통 대기실 (모든 게임)
- 로비에서 게임을 고르고 방 만들기 → 그 게임의 방 → **공통 대기실**.
- 왼쪽: "○○의 방" 제목, 게임 간단 설명, 그 아래 게임 시작 전 설정 전부. 나머지: 참가자(이름·프로필·칭호), 채팅, 게임 시작 버튼(대기실 안. 상단 줄에는 두지 않는다).
- 방 안에서 게임을 바꾸지 않는다(홀덤↔블러핑 전환 제거, 로비에서 따로 고른다). 미니게임만 방 안에서 종목을 정한다.
- 갱스껄 색 고르기는 대기실에서 각자.
- 게임이 끝나면 대기실로 돌아온다(같은 사람, 방장이 설정을 바꿔 다시 시작). 포커는 지금처럼 테이블에서 판이 이어진다.
- 코드 전에 시안을 사용자에게 보여 주고 확정받는다.

### 방 운영
- 게임 중 나가기는 확인 창(결과 안내 포함). 대기실에서는 바로 나간다.
- 강퇴: 모든 게임. 소리 버튼: 모든 게임(라이어도 사이트 소리 끄기를 따른다).
- 끊김 유예: 모든 게임 60초(GRACE_MS). 방장은 끊긴 즉시 넘기지 않고, 유예가 끝나 나간 것으로 처리될 때 연결된 사람에게 넘긴다.
- 판이 끝날 때마다 갱식 코인을 몇 개 받았는지 알려 준다(모든 게임).
- 갱스껄에 코인을 붙인다.
- 관전: 아이디가 `관전` + 숫자(관전1, 관전2 …)인 계정은 게임에서 제외되고 관전만 한다. 정원에 포함하지 않고 방마다 관전 자리 최대 4. 채팅·이모티콘 가능(그 게임의 채팅 규칙을 따른다). 관전자 기기에는 비밀을 보내지 않는다.
- 관리자 봇: 갱스껄·미니에 간단한 봇(합법 수 중 무작위).

### 라이어
- 투표가 무산되거나 아무도 투표하지 않아도 판을 끝내지 않는다. 연장 투표로 이어 간다. 판이 끝나는 것은 투표로 한 명을 처형했을 때뿐이다.
- 안전장치: 방장의 "판 끝내기" 버튼은 남긴다.
- 제시어 제출(라이어 정답 맞히기) 화면에서도 첫 발언 기록을 볼 수 있게 한다.
- 첫 설명 바퀴 수 설정: 1~3, 기본 1.

### 갱스껄
- 프로필 사진이 있는 사람의 원판은 게임 내내, 공개 연출에서도 해골 그림 대신 그 사람 프로필 사진으로 보인다(공개 연출에서 해골로 보이는 오류 고침).

### 미니게임
- 방 만들기·대기실은 다른 게임과 같다.
- 체스: 국제 규정(캐슬링, 앙파상, 승급, 스테일메이트, 3회 반복, 50수) 점검·보완.
- 오목: "렌주룰(흑만 3-3·4-4·장목 금지)" / "제한 없음" 선택.
- 승부 방식: 단판 / N판 M선승 설정. 종목: 한 종목 고정 / 랜덤 / 순서대로.
- 코인 베팅(대기실 왼쪽): 둘이 각자 가진 한도 안에서 적고, 두 사람이 건 수가 같아야 내기가 성립한다. 한도 없음. 0이면 내기 없는 판. 베팅은 선택.
  중간에 나가거나 60초 넘게 끊기면 패배(코인 잃음), 무승부는 돌려준다. 베팅한 판에서도 원래 승리 코인은 준다.
  "상대 베팅에 맞추기" 버튼: 누르면 내가 건 수를 상대가 건 수로 맞춘다(내 보유 코인이 모자라면 눌리지 않고 이유 표시). (2026-11-13 사용자 추가 요청)

### 관리자
- 세부 설정 페이지(관리자만 이동): 게임별 승리·완주 코인 수, 코인 교환 시세. 저장은 DB, 서버 재시작 없이 적용.
- 상점 가격은 상점 개편 때 붙인다(이번에는 틀만).

### 총괄 판단으로 정한 것
- 요트 색: 어느 화면에서든 한 사람 한 색(6색 규칙 하나).
- 갱식마인드 최종 순위에도 프로필 사진(공용 프로필 부품).
- 데모 페이지·자리표시 파일: 시험에 쓰는 것만 남기고 지운다.
- 포커 프로필 사진은 다른 게임처럼 `faces` 알림으로 한 번만 보낸다.

## 2. 일하는 방식
- 총괄(Fable): 방향·약속 문서·분배·병합·마지막 점검·보고.
- 작성: Sonnet, 구역별 병렬, 각자 git 워크트리. 공통 뼈대만 Opus 가 쓴다.
- 검토: 묶음마다 Opus. 직접 고치지 않고 수정 지시. 되돌리기는 최대 2번, 넘으면 총괄이 판단.
- 시험: 과제를 합칠 때마다 `npm run check`, 묶음 끝에 `npm test`. 배포마다 사용자에게 "직접 확인할 목록"을 준다. 3D·소리·iPad 는 미확인으로 보고.
- 배포는 3번으로 나눈다. 배포 직전 버전에 이름표를 남긴다. 배포 전 사용자에게 묻는다(진행 중인 방이 끊긴다).
