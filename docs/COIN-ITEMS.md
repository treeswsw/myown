# 칭호·치장템 목록 초안 (사용자와 정하는 중, 2026-11-13)

방향(사용자): 존나 웃기게, 디씨 감성, 수위는 가능한 제일 세게. 낮은 등급 = 욕·비하, 중간 = 컨셉충, 높은 등급 = 효과 붙은 서사 칭호.
제외(사용자): 설명조·흔한 신세 한탄 드립(강원랜드에 집 판 놈, 탄핵 2회차 같은 것). 짧고 뜬금없고 실제 밈을 건드리는 것만.
제외: 특정 집단(여성·지역·장애·인종) 겨냥 혐오 표현, KKK.
분류: 칭호 / 모자 / 기타 악세 / 페이셜(수염·화장) + 기존 테두리·글자 색·정장.
등급: 잡템(회색) / 흔템(파랑) / 컨셉(보라, 글자 색) / 레전드(금, 움직이는 효과) / 갱식(무지개, 화면 연출).
뽑기: 카드 뽑기 = 칩(SPEC 22-15), 캡슐 뽑기(가챠 기계) = 칭호·치장템. 중복은 조각. 수집 보상(잡템 칭호 20개 → 갱식 칭호) 검토 중.

## 칭호
- 잡템: 좆븅신, 씹버러지, 개좆밥, 아메바, 인간 쓰레기, 좆도 없는 놈, 씹덕, 개노답 삼형제 중 막내, 럭키비키, 롤대남, 애미 카드 긁는 놈, 모쏠 아다, 딸쟁이, 탈모 확정, 도태남, 좆소 다님, 백수 3년차, 방구석 좆문가, 엄마가 포기함, 숨쉬는 게 민폐, 뇌에 주름 없음, 유전자 낭비, 틀딱, 급식충, 국밥충, 좆망 인생
- 흔템: 칩 셔틀, 걸어다니는 ATM, 올인 박고 뒤짐, 폴드밖에 못하는 쫄보, 뻥카 치다 걸린 병신, 대가리에 총 맞는 게 취미, 6발 중 6발, 라이어 티 존나 남, 제시어 스포한 새끼, 주사위한테 쌍욕 먹음, 요트 0점 장인, 발가락으로 그림, 그림 보고 다들 토함, 3초 전엔 부자였음, 한강 수온 체크 중
- 컨셉: 공익 전투광, 근첩, 극우 유튜버, 급진 좌파, 박사모, 태극기 부대, 개딸, 일베 눈팅러, 틀튜브 맹신자, 부정선거 연구가, 음모론 박사, 국뽕 중독자, 주갤 망령, 헬창, 방위 출신, 관심병사, 군필 여고생, 사이비 교주
- 레전드(효과): 지옥에서 돌아온(불꽃), 국정원 지하에 수감된(철창·경광등), 윤어게인(태극기 펄럭), 동덕여대(래커칠 흘러내림), 페미 선봉장(확성기 진동) — 후보(사용자 확인 전): 국회 담 넘은(담장 넘는 실루엣), 계엄 선포한(탐조등·사이렌), 관저에서 버틴(철조망), 입틀막 당한(손이 글자를 가림), 광화문 지박령(촛불과 태극기 반반), 여의도에서 쫓겨난(발자국), 구치소 독방 쓰는(창살 그림자), 바이든 날리면(자막이 바뀜)
- 갱식: 어딘가를 찢고나온(사용자 지정, 최고 등급: 칭호판이 찢어지며 글자가 튀어나옴), 갱식 그 자체(무지개·입장 팡파레), 신이 버린 새끼 / 신이 내린 손, 잭팟의 주인(카드 뽑기 금고 전용), 이 방의 호구(머리 위 화살표), 좆븅신 중의 좆븅신(잡템 칭호 20개 수집 보상)

## 모자
- 잡템: 깔깔이 군모, 예비군 모자, 비닐봉지, 신문지 모자, 팬티 뒤집어쓰기
- 흔템: 딜러 챙모자, 삿갓, 수건 양머리, 배달 헬멧, 변기 뚜껑
- 컨셉: 태극기 머리띠, "단결 투쟁" 머리띠, 탈모 가발, 스킨헤드, 죄수 모자
- 레전드: 왕관, 방탄모 + 야간투시경, 불타는 대가리
- 갱식: 천사 고리, 갱식 사장 모자
