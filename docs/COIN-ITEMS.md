# 칭호·치장템 목록 (2026-11-13 사용자와 정함. 품목 추가·삭제는 여기 먼저 고치고 shared/coin/items/*.js 에 반영)

- 방향(사용자): 존나 웃기게, 디씨 감성, 수위는 가능한 제일 세게. 짧고 뜬금없고 실제 밈을 건드리는 것. 설명조·흔한 신세 한탄 드립은 뺀다.
- 넣지 않는 것: 특정 집단(여성·지역·장애·인종)을 겨냥한 혐오 표현, KKK.
- 분류(slot): 칭호 title / 모자 hat / 기타 악세 acc / 페이셜 face / 테두리 frame / 글자 색 color / 정장 suit.
- 등급(g): 0 잡템(회색 #9a9a9a) / 1 흔템(파랑 #3d8bff) / 2 컨셉(보라 #b45cff) / 3 레전드(금 #ffc93c, 움직이는 효과) / 4 갱식(무지개, 화면 연출).
- 붙는 방식(프사가 얼굴이 아니어도 맞게): 가장자리형 edge(동그란 프사 테두리에 고정: top/side/bottom/ring) / 덮개형 cover(사진 전체 위에 한 겹) / 스티커형 sticker(본인이 끌어서 위치·크기를 맞춤, 기본은 가운데).
- 얻는 곳: 캡슐 뽑기(전부). 잡템·흔템은 상점에서도 판다. "잭팟의 주인"은 카드 뽑기 금고 전용, "좆븅신 중의 좆븅신"은 잡템 칭호 20개 수집 보상.
