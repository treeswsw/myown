# 제시어 — 스타 버전 (v1.0)

- 스타크래프트 유즈맵 「라이어 게임」(LIARGAME v2.2) 기본 모드 제시어를 옮긴 묶음. 출처 분석은 docs/REF-SCX.md.
- "내 버전"(docs/WORDS.md)과 따로 두고, 방장이 방 설정에서 어느 묶음을 쓸지 고른다.
- 괄호 = 정답 맞히기에서 함께 인정할 다른 이름(맵의 복수정답 표). 브랜드의 성인용 단어 2개는 뺐다.
- 맵의 복수정답 중 다른 단어와 겹치거나 뜻이 다른 것은 뺐다: 타이어→바퀴, 매트리스→침대, 소화기→소화전, 로션→지점토, 놀부→흥부, 로미오→줄리엣, 동물원→사파리, 금은방→전당포, 프로그래머→해커, 대통령→총리.
- 형식은 내 버전과 같다(주제마다 한 줄, " · "로 구분).
