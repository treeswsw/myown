# 갱스껄 기획서 (GDD) — v1.0

같은 사이트의 다섯 번째 게임. 원판을 엎어 쌓고, 꽃만 뒤집겠다고 큰소리치는 블러핑 게임(3~6명).
이름은 `shared/gsk/name.js` 의 `GAME_NAME = '갱스껄'` 한 곳에만 적는다. 코드 이름은 `gsk`, CSS 는 전부 `.gk-`, 요청 봉투는 `{t:'gk', a, ...}`, 방 종류는 `mode:'gsk'`.
이 문서는 갱스껄에 한해 SPEC 보다 우선한다. 뒤 절이 앞 절보다 우선한다.

## 1. 뼈대

- 3~6명. 같은 아이디·프로필 사진·로비·채팅·이모티콘·사운드를 쓴다. 포커 칩과 연결 없음.
- 2D 화면(3D 장면 안 씀). 위에서 내려다본 나무 탁자, 둘레에 사람마다 사각 개인판, 그 위에 둥근 원판 더미.
- **가로 전용**(세로는 사이트 `#rotate` 안내, 요트와 같음). PC·iPad·휴대폰 가로.
- 관전 가능(판 도중 들어온 사람은 다음 판부터 참가). 전적: `users.stats.gsk = {games, wins}`(새 표 없음).
- 디자인: 사용자가 준 레퍼런스(나무 탁자, 6색 사각 개인판에 원형 문양, 6색 둥근 원판에 문양 테두리)의 **느낌**을 따른다.
  원작 그림을 베끼지 않고 문양은 우리가 새로 그린다(SVG). 원작 이름·그림은 쓰지 않는다.
  - 꽃 원판: 그 색의 문양 테두리 + 가운데 꽃 그림.
  - 해골 원판: 같은 테두리 + 가운데 원 안에 **그 사람의 프로필 사진을 꽉 차게**(원형으로 잘라 cover). 사진이 없으면 해골 그림(레퍼런스 느낌의 문양형 해골).
  - 원판 뒷면: 그 색의 문양(꽃·해골 구별 불가, 모두 똑같아야 한다).
  - 개인판: 앞면(기본)과 뒷면(도전 1번 성공 = 1점, 다른 문양·금색 테두리).
- 색 6개(순서 고정, 번호 0~5): 0 초록 `#5fbf3a` · 1 보라 `#7a3fa8` · 2 노랑 `#e9a21b` · 3 빨강 `#d42a2a` · 4 분홍 `#ec2f7d` · 5 파랑 `#3e8fa6`.

## 2. 규칙 (사용자 제공 규칙 13줄 + 원작 공식 규칙)

1. 각자 색 하나를 고르고 개인판과 원판 4장(꽃 3, 해골 1)을 가진다.
2. **라운드 시작(준비)**: 살아 있는 모두가 동시에 손의 원판 1장을 자기 개인판 위에 엎어 놓는다. 모두 놓으면 시작 사람부터 차례.
3. 차례(시계 방향, 화면에서는 자리 순서): **원판 추가**(손의 1장을 자기 더미 맨 위에 엎어 쌓기) 또는 **도전**(숫자 n 부르기) 중 하나. 손에 원판이 없으면 도전만 할 수 있다.
4. 쌓인 순서는 바꿀 수 없다.
5. 도전 숫자 n: `1 ≤ n ≤ 탁자 위 원판 합계`. 도전이 시작되면 **경매**: 도전한 사람 다음 사람부터 시계 방향으로 "더 높은 숫자" 또는 "패스". 한 번 패스하면 이번 경매에 다시 못 낀다. 한 명만 남거나 누군가 합계와 같은 숫자를 부르면 끝. 그 사람이 **도전자**.
6. 도전자는 부른 숫자만큼 뒤집어야 한다. **먼저 자기 더미를 전부 뒤집는다**(서버가 자동으로, 위에서부터). 그다음 원하는 사람의 더미를 골라 맨 위부터 한 장씩 뒤집는다.
7. 뒤집은 것이 모두 꽃이고 n장에 이르면 **성공**: 개인판을 뒷면으로(1점). 해골이 하나라도 나오면 그 즉시 **실패**.
8. 실패: 도전자는 자기 원판(손 + 판 위 전부) 중 1장을 잃는다. **해골 주인**이 도전자의 원판을 뒷면으로 섞은 채 하나를 눌러 고른다. **자기 해골이었으면 도전자가 직접 고른다**(자기 원판이므로 앞면을 보고 고른다). 버린 원판이 무엇인지는 도전자 본인만 안다(해골 주인도 모른다).
9. 다음 라운드 시작 사람 = 도전자. 도전자가 실패로 탈락했으면 그 해골 주인(자기 해골이었으면 도전자 다음 살아 있는 사람).
10. 원판 4장을 모두 잃으면 탈락(관전처럼 탁자에 흐리게 남는다).
11. 승리: **먼저 2점**(개인판 두 번째 성공) 또는 **혼자 남음**.
12. 라운드가 끝나면(성공·실패 모두) 모든 원판이 각자의 손으로 돌아간다.

## 3. 웹에서 정한 것

- 차례 시간 제한 **없음**(✅ 사용자). 자동 행동 없음. 준비 단계도 모두 놓을 때까지 기다린다.
- 끊김: 끊긴 사람을 기다린다. 끊긴 지 `GRACE_MS`(60초, 사이트 공통)면 기권 → 탈락. 돌아오면 그대로 이어서.
- 실패 벌칙 고르기: ✅ 사용자 "해골 주인이 직접 고름". 고르는 사람이 기권·나가기로 사라지면 서버가 crypto 난수로 고른다.
- 판 도중 누가 기권·나가기를 하면(탈락): 판정이 나기 전(setup·turn·bid·flip)이면 그 라운드는 **무효**. 판정이 난 뒤(reveal·penalty)에 도전자가 아닌 사람이 나가면 결과(점수·벌칙)를 그대로 진행하고 나간 사람만 탈락(해골 주인이 나갔으면 벌칙은 난수로). 모든 원판을 손으로 돌리고 같은 시작 사람(그 사람이 빠졌으면 다음 살아 있는 사람)으로 새 라운드. 벌칙 고르기 중이었고 빠진 사람이 고르는 사람이면 난수로 고른 뒤 진행. 빠진 사람이 도전자이면 벌칙 없이 새 라운드. 1명 남으면 그 사람 승리.
- 연출 대기 시간(서버가 잼, `endsAt`): 뒤집기 한 장 공개 뒤 성공·실패 판정 표시 `REVEAL_MS = 2500`, 라운드 사이 `BETWEEN_MS = 1500`. 자기 더미 자동 뒤집기는 한 장마다 `AUTO_FLIP_MS = 500` 간격.
- 무작위는 전부 crypto(첫 시작 사람, 자리 순서, 벌칙 섞기, 대신 고르기). **`Math.random` 금지**(gsk 폴더 전체).
- 자리 순서 = 판 시작 때 crypto 로 섞는다. 첫 라운드 시작 사람도 crypto.
- 색: 방 대기(`lobby`) 단계에서 각자 고른다(먼저 고른 사람 것, 겹치면 거절). 안 고른 사람은 시작할 때 남은 색을 들어온 순서대로.
- 방장만 시작, 접속 중 3명 이상. 결과 화면에서 방장이 "한 판 더"(`start`).

## 4. 비밀 지키기 (반드시. `test/gsk/leaks.test.js`)

- 엎어 놓은 원판이 꽃인지 해골인지는 **주인 기기에만** 보낸다. 다른 사람·관전자 기기로 가는 어떤 메시지(상태·이벤트·오류·순서·길이)에도 드러나면 안 된다.
- 꽃을 놓든 해골을 놓든 다른 사람이 받는 메시지는 **모양과 길이까지 같다**. 원판에 고정 번호(예: 3번=해골)를 붙여 보내지 않는다.
- 손에 무엇이 남았는지도 주인만 안다. 다른 사람은 장수만.
- 벌칙으로 버린 원판의 종류는 도전자 본인만 안다. 해골 주인에게 보이는 뒷면 칸의 순서는 crypto 로 섞고, 그 순서는 서버만 안다.
- 뒤집혀 공개된 원판만 모두에게 보낸다(종류 + 주인). 라운드가 끝나 손으로 돌아가면 다시 비밀.
- 사용자 글자는 `textContent` 로만. 방 상태에는 프로필 사진을 넣지 않는다(`faces` 알림, 요트와 같음). 해골 원판 사진은 화면이 `faces` 로 받은 사진을 쓴다.

## 5. 한 판의 진행 (단계 `step`)

`lobby`(방 대기) → 판 시작 → [라운드: `setup` → `turn` ⇄ … → `bid` → `flip` → `reveal` → (`penalty`) → `between`] 반복 → `result`.

| step | 누가 무엇을 | 끝 |
|---|---|---|
| `setup` | 살아 있는 모두 `place` 1번(동시) | 모두 놓으면 `turn`(시작 사람) |
| `turn` | 차례인 사람 `place` 또는 `bid` | `place` → 다음 사람 `turn`. `bid` → `bid` 단계(합계와 같으면 바로 `flip`) |
| `bid` | 경매 차례인 사람 `bid`(더 큰 수) 또는 `pass` | 남은 1명 또는 합계 도달 → `flip` |
| `flip` | 서버가 도전자 더미 자동 공개, 이어서 도전자가 `flip {p}` | 해골 → `reveal`(실패), n장 꽃 → `reveal`(성공) |
| `reveal` | 없음(`REVEAL_MS`) | 성공: 2점이면 `result`, 아니면 `between`. 실패: `penalty` |
| `penalty` | 고르는 사람 `discard` | 버림 → (탈락 처리) → `between` 또는 `result` |
| `between` | 없음(`BETWEEN_MS`), 원판 손으로 | 다음 라운드 `setup` |

## 6. 화면 (시안 `design/gsk/index.html`, 확정 뒤 `client/src/gsk/`)

- 탁자: 나무 결 배경, 가운데 타원 공간. 자리는 내 자리가 아래 가운데, 나머지는 시계 방향으로 둘레에.
- 자리마다: 개인판(사각, 색, 앞/뒷면) + 그 위 원판 더미(엎은 원판이 살짝 어긋나게 쌓임, 뒤집힌 것은 앞면) + 프로필·이름·남은 원판 수(손 n · 판 n) + 상태 표시(차례, 패스, 끊김, 탈락).
- 가운데: 지금 상황 한 줄(예: "철수 님 차례", "영희 님 도전 5"), 경매 중이면 지금 숫자·부른 사람·패스한 사람, 뒤집기 중이면 "3 / 5".
- 아래: 내 손(원판 앞면이 보이게, 내 해골 = 내 프로필 사진). 누르면 놓기. 그 옆 버튼: `도전`(숫자 고르기: −/+ 와 숫자, 최소~합계), 경매 중 `올리기`/`패스`.
- 뒤집기: 도전자 화면에서 남의 더미를 누르면 맨 위가 뒤집힌다(뒤집히는 움직임 0.4초). 모두에게 같은 장면.
- 벌칙: 고르는 사람 화면 가운데에 도전자의 원판이 뒷면으로 섞여 n칸 나오고 하나를 누른다. 자기 해골이면 도전자 화면에 앞면으로 나온다. 나머지 사람은 "○○ 님이 고르는 중".
- 결과: 승자 큰 프로필 + "갱스껄 승리!", 순위(점수·남은 원판), 방장 "한 판 더".
- 휴대폰 가로(높이 < 500): 자리를 작게, 내 손은 아래 가장자리에 작게.
- 움직임: 원판 놓기(손에서 미끄러져 쌓임), 뒤집기, 성공 시 개인판 뒤집힘, 실패 시 해골 흔들림.
- ✅ 사용자: "뒤집어지는 모션이랑 딱 해골 나왔을 때 모션이 맛있었으면". **뒤집기와 해골 공개 연출은 이 게임의 핵심 연출**로 Fable 이 따로 맡는다(G6). 뒤집기: 살짝 들어 올림 → 3D 회전(CSS perspective/rotateY) → 탁 내려앉는 반동·그림자 변화·작은 먼지/반짝임. 해골 공개: 뒤집히는 중간에 한 박자 멈칫(긴장) → 해골(사진) 쾅 등장, 화면 살짝 흔들림·어두워짐·붉은 빛 번짐·해골 주인 자리 강조, 도전자 자리 움찔. 꽃이 연속으로 나올 때는 점점 고조(소리 높이·반짝임 증가), 마지막 장 성공은 시원한 터짐. 2D(CSS·SVG·캔버스)만, GPU 없는 시험(`?nogl=1`)에서도 돈다. 모두 같은 순간에 같은 연출(서버 이벤트 기준). 느낌은 실기기 확인 필요. 소리는 사이트 소리 설정을 따른다(놓기·뒤집기·성공·실패, `client/src/gsk/audio.js`).

## 7. 규칙 체크리스트 (13항목)

1. 누가: 사이트 회원, 3~6명 + 관전. 로그인은 사이트 공통.
2. 저장: `users.stats.gsk = {games, wins}` 만. 방은 메모리.
3. 흐름: 5절.
4. 끝 조건·시간: 사람 행동은 시간 제한 없음. 연출만 서버 `endsAt`(3절).
5. 끊김: 기다림, 60초 뒤 기권 → 탈락(3절). 재접속하면 같은 상태 그대로. 판 도중 새 사람은 관전.
6. 점수: 개인판 2점이 승리. 원판 0장 탈락.
7. 결과: 결과 화면이 방장이 다시 시작할 때까지 남는다.
8. 만나기: 로비 방 목록·방 코드(사이트 공통). 방장: 시작·한 판 더.
9. 예외: 합계보다 큰 숫자·같은 숫자 다시 부르기·차례 아닌 사람 요청·손에 없는 종류 놓기·이미 공개된 더미·자기 더미 고르기 → 거절(9절 오류). 색 겹침 거절. 동시 입력은 서버 도착 순.
10. 기기: PC·iPad·휴대폰 가로, 터치. 세로는 `#rotate`.
11. 소리·움직임: 있음, 사이트 소리 설정을 따름.
12. 배포: Render, `main`. 스위치 `GSK`(11절).
13. 확인 시나리오: 12절.

## 8. 서버 판정 원칙

- 모든 규칙·시간·무작위는 서버. 화면은 서버 상태만 그린다.
- 엔진(`shared/gsk/game.js`)은 순수 함수: 시계·난수·네트워크 없음. 지금 시각과 난수 함수는 인자로 받는다. 받는 사람별 `viewFor(state, id)`.
- room(`server/gsk/room.js`)은 모든 요청 처리 전에 `tick(now)` 를 부르고, 타이머는 엔진의 `nextDeadline(state)` 하나.

### 9-2. 서버 → 화면

- `{t:'me', ..., gsk:'off'|'test'|'on'}` — `me` 에 `gsk` 칸 추가.
- `{t:'rooms', list}` 항목: `mode:'gsk'`, `max:6`, `phase`.
- `{t:'room', state}` (`mode:'gsk'`, 받는 사람 시점):

```js
{
  code, mode: 'gsk', hostId, you, now,
  phase: 'lobby' | 'playing' | 'result',
  gameNo,
  players: [{ id, name, connected, awayUntil: epochMs | null, spectating }],   // 방에 있는 사람 전부(들어온 순서)
  seats: [{                       // lobby: 관전 아닌 사람(들어온 순서). playing·result: 이 판 참가자(자리 순서 = 시계 방향)
    id, name,
    color: 0..5 | null,           // lobby 에서 안 골랐으면 null
    points: 0 | 1 | 2,            // 개인판 1 = 뒷면
    discs: 0..4,                  // 남은 원판 수(손 + 판 위)
    hand: 0..4,                   // 손에 있는 장수
    stack: 0..4,                  // 판 위에 놓인 장수
    shown: ['F' | 'S', ...],      // 판 위 원판 중 뒤집혀 공개된 것, 위에서부터(공개된 것만, 길이 ≤ stack)
    placed: bool,                 // setup 단계에서 이번에 놓았는가
    passed: bool,                 // 이번 경매에서 패스했는가
    out: null | 'lost' | 'away' | 'leave',   // 탈락 이유(원판 0 / 끊김 60초 / 나감)
  }],
  step: null | 'setup' | 'turn' | 'bid' | 'flip' | 'reveal' | 'penalty' | 'between',
  round: 0..,                     // 판 시작 전 0
  starter: id | null,             // 이번 라운드 시작 사람
  turn: id | null,                // turn·bid 단계에서 행동할 사람. flip 단계에서는 도전자. 그 밖 null
  waiting: id | null,             // 행동할 사람이 끊겨 기다리는 중이면 그 id
  total: 0..24,                   // 판 위 원판 합계 = 부를 수 있는 최대
  bid: null | { n, by: id },      // 지금 가장 높은 숫자와 부른 사람
  challenger: id | null,          // flip·reveal·penalty 단계의 도전자
  need: 0.., flipped: 0..,        // 뒤집어야 할 수(= bid.n), 지금까지 뒤집은 꽃 수
  outcome: null | { ok: bool, skullOf: id | null },   // reveal·penalty·between: 성공/실패, 실패면 해골 주인
  penalty: null | { by: id, target: id, n, faceUp: bool },  // 고르는 사람, 도전자, 칸 수(도전자 남은 원판 수), 자기 해골이면 faceUp
  endsAt: epochMs | null,         // reveal·between·자동 공개 대기 끝
  mine: null | {                  // 받는 사람이 참가자일 때만. 남에게는 절대 보내지 않는다
    hand: { F: n, S: n },         //   손
    stack: ['F' | 'S', ...],      //   내 더미, 아래에서 위로
    lost: ['F' | 'S', ...],       //   이번 판에 잃은 원판 종류(나만 앎)
  },
  result: null | { reason: 'points' | 'alone', winner: id | null,
                   ranks: [{ id, name, points, discs, rank }] },   // 점수 큰 순, 같으면 남은 원판 많은 순, 탈락자는 늦게 탈락한 순
}
```

- `mine` 말고는 같은 방 모두(관전자 포함)가 같은 값을 받는다(`you` 제외).

## 12. 완성 확인 시나리오

1. **한 판 끝까지**: 3명이 `?gsk=1` 로 들어와 색을 고르고 시작. 모두 원판을 놓고, 차례대로 쌓고, 한 명이 도전 → 경매 → 자기 더미 자동 공개 → 남의 더미 뒤집기 → 성공하면 개인판이 뒤집힌다. 두 번 성공한 사람이 이기고 결과 화면, "한 판 더"로 다시 시작.
2. **실패와 탈락**: 해골이 나오면 해골 주인 화면에만 뒷면 칸이 뜨고 하나를 누르면 도전자 원판이 1장 줄어든다. 자기 해골이면 도전자가 앞면을 보고 고른다. 4장 다 잃으면 탈락, 혼자 남으면 승리.
3. **비밀**: 꽃·해골을 놓을 때 다른 사람 기기가 받는 메시지가 같다. 공개 전 원판 종류·손 구성·버린 종류가 남에게 가지 않는다(자동 시험).
4. **끊김**: 차례인 사람이 새로 고침하면 그대로 이어진다. 60초 넘게 끊기면 탈락하고 라운드가 무효로 다시 시작된다.
5. **사진 해골**: 프로필 사진이 있는 사람의 해골 원판에는 그 사진이 원 안에 꽉 차게, 없는 사람은 해골 그림. (모양은 실기기 확인 필요)
6. **스위치**: `GSK=off` 면 흔적 없음, `test` 면 `?gsk=1` 에서만 칸. 다른 게임은 그대로(`npm test`).
