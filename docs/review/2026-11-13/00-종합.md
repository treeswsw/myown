# 코드 검토 종합 (2026-11-13, 기준 버전 `prototype` = ca68b8b)

Opus 검토자 10명이 읽기만 했고, 코드는 하나도 고치지 않았다. 시험·서버도 돌리지 않았다(코드를 읽고 낸 결론).
"확인"은 총괄이 코드에서 직접 다시 본 것, "보고"는 검토자 보고만 있는 것, "미확인"은 실기기가 필요한 것이다.

## 1. 한눈에

- 서버를 당장 죽이는 입력, 코인 이중 지급, 사용자 글자 innerHTML, 판정용 Math.random 은 **없다**.
- 가장 큰 문제는 예상대로 **복사**다. 같은 코드가 게임마다 5~7벌 있고, 그 때문에 실제로 어긋난 곳이 여러 군데 나왔다.
- 공통화하기 전에 **안전망(시험)** 이 먼저 필요하다. 요트·미니는 채팅·이모티콘 시험이 0건이다.
